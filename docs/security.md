# HermesMesh Security

## Security Model

HermesMesh follows a defense-in-depth approach:

1. **Enrollment Tokens** — Single-use, time-limited tokens for node registration
2. **Transport Security** — TLS for all communications
3. **Authentication** — API keys for user access
4. **Authorization** — Role-based access control (RBAC)
5. **Audit Logging** — All administrative actions recorded
6. **Node Isolation** — Nodes can't access each other directly

## Roles

| Role | Permissions |
|------|-------------|
| `ADMIN` | Full cluster management |
| `OPERATOR` | Submit/manage tasks, view nodes |
| `VIEWER` | Read-only access |

## Enrollment Tokens

- Generated by administrators via API
- Single-use only
- Expire after 24 hours (configurable)
- Bound to specific node roles

```bash
# Create enrollment token
curl -X POST http://localhost:8000/api/v1/enrollment/create \
  -H "Authorization: Bearer <admin_token>"
```

## Transport Security

Always use TLS in production:

```bash
# Generate self-signed cert (development only)
openssl req -x509 -newkey rsa:4096 -keyout key.pem -out cert.pem -days 365

# Run with TLS
uvicorn hermesmesh.server.api:app --ssl-certfile cert.pem --ssl-keyfile key.pem
```

## Network Security

- Controller binds to `0.0.0.0` by default — restrict with firewall
- Agents connect outbound to controller (no inbound ports needed)
- WebSocket connections use same TLS as REST API

## Audit Log

Every administrative action is recorded:

```json
{
  "actor": "admin",
  "action": "node_register",
  "target": "node-uuid",
  "details": {"hostname": "node1", "platform": "linux"},
  "timestamp": "2024-01-01T00:00:00Z"
}
```

## Secrets Management

- API keys stored hashed in database
- Enrollment tokens stored encrypted
- Node credentials rotated automatically
- No secrets in git (use environment variables)

## Reporting Security Issues

If you discover a security vulnerability, please report it privately:

1. Email: security@hermesmesh.dev
2. Do NOT open a public issue
3. Allow 48 hours for initial response

## Security Checklist

- [ ] TLS enabled for all connections
- [ ] Strong admin API key configured
- [ ] Enrollment tokens expire within 24 hours
- [ ] Firewall rules restrict controller access
- [ ] Audit logging enabled
- [ ] Database backups encrypted
- [ ] Regular security updates applied
